## 5. Domain `.id` — belakangan, jangan beli dulu

**Keputusan Fase A:** domain `designtuntas.id` **ditunda**.

Beli nanti jika:
- Brand sudah nyaman dipakai
- Sudah ada inquiry/order
- Siap ~Rp 150–300rb/tahun

Cara hubungkan (nanti):
1. Beli di registrar (Niagahoster / Rumahweb / PANDI partner)
2. Vercel → Project designtuntas → Settings → Domains → add `designtuntas.id`
3. Ikuti DNS yang diminta Vercel
4. Update `NEXT_PUBLIC_SITE_URL`

Sementara pakai: https://designtuntas.vercel.app
